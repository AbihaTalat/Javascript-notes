Iterator:
An iterator is an object that returns values one at a time using the next() method.
Each call to next() returns an object containing:
-value
-done

Generator:
A generator is a special function declared with function*. It can pause execution using the yield keyword and continue later. 

Learning Points:
-Iterators provide sequential access to data.
-Generators automatically create iterators.
-The yield keyword pauses function execution.
