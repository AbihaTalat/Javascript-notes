ES6 + Syntax:
ES6 introduced modern JS features that make code easier to read and write. 

Destructuring:
Destructuring allows values to be extracted from arrays and objects. 

Spread Operator(...):
The spread operator copies or expands arrays and objects.

Optional Chaining(?.):
Optional chaining safely accesses properties that may not exist.

Learning Points:
-Destructuring reduces repetitive code.
-Spread syntax makes copying easier.
-Optional chaining prevents errors when accessing missing properties.
