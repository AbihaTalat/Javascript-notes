ES Modules and CommonJS
Modules allow Javascript code to be divided into separate files.

CommonJS:
CommonJS uses;
-require()
-module.exports

It is mainly used in Node.js

ES Modules:
They use:
-import
-export

They are the standard module system in modern JS

Learning Points:
-Modules improve code organization
-CommonJS and ES Modules use different syntax.
-Importing and exporting code makes applications easier to maintain.
