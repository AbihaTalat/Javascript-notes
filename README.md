# Javascript-notes Repository
This repository contains my notes and code examples on important modern Javascript concepts. The purpose of this repository is to understand how Javascript objects inherit properties, use ES6+ features, work with iterators and generators, and organize code using modules. 

# Topics Covered
-Prototype Chain
-ES6 + Syntax
-Generators and Iterators
-ES Modules and CommonJs

Each folder contains:
-notes.md - Concept explanations and Learning notes
-examples.js - Small code examples
